# Double-Click Deposit Worn Items

Double-Click Deposit Worn Items is a RuneLite plugin designed to prevent accidental depositing of worn equipment when using the bank interface.

When enabled, the “Deposit worn items” button in the bank requires a second click within a short time window before the action is performed. A visual overlay appears on the button to clearly indicate that a second click is required.

# Features

- Requires a double-click to deposit equipped items

- Visual progress overlay on the deposit button

- Fully configurable confirmation window

- Optional color and opacity customization for the overlay
